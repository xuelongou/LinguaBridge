# 语桥 LinguaBridge · MVP 演示包

面向课程项目答辩的可演示原型：方言 / 多语言双向互译 + 7 个固定手语词动作示意。
纯静态网页，解压后在任意 Windows 电脑的浏览器中展示；**长句翻译在联网时调用在线翻译接口，断网自动回落内置离线词库**。

## 一、现场启动步骤（明天演示照这个来）

1. **把整个 zip 解压出来**，不要只单独拷贝 `index.html`（必须连同文件夹一起解压）。
2. 进入解压后的文件夹，双击 **`启动演示.bat`**，浏览器会自动打开演示页面。
   - 如果双击 bat 被安全软件拦截，也可以直接双击 `index.html`。
3. 浏览器弹出摄像头权限请求时，点 **「允许」**；手语模块需要用到摄像头取景。
4. 顶部导航可在四个页面之间切换：首页 / 方言·多语言互译 / 手语演示 / 答辩说明。

## 二、演示兜底方案（防止现场翻车）

- **摄像头打不开 / 被拒绝 / 设备占用**：手语页有三条备用路径——
  1. 点「上传图片」选一张手势图；
  2. 直接点击右侧手语词卡；
  3. 按键盘数字键 **1–7** 选中对应词。
- **长句翻译失败 / 现场断网**：在线接口不可用时，英语会回落内置词表和常用句式规则做简单翻译，其他语种请点击离线词卡演示已收录短句。演示前建议先在现场网络下打开互译页，输入一句长句确认在线翻译可用。
- **语音朗读不可用**：朗读依赖系统自带语音包，失败时直接展示文字结果即可。
- **3D 舞台不显示 / 浏览器不支持 WebGL**：舞台会自动回退到平面手势示意图，词卡、动作分解和自动演示不受影响。
- **浏览器兼容**：推荐用 Chrome / Edge 打开；不要用 IE。

## 三、3 分钟演示脚本

1. **开场（20 秒）**：介绍项目名 LinguaBridge，目标是帮方言使用者、外语沟通者和听障人群做跨语言沟通，今天演示 MVP 原型。
2. **方言·多语言互译（60 秒）**：
   - 源语言选「四川话」，目标语言选「英语」；先点词卡展示离线短句；
   - 在输入框打一句长句（例如“我想去医院看医生”），展示在线翻译结果；
   - 目标语言切换为日语、俄语各看一遍；点「⇄」交换源和目标，演示反向链路；
   - 每轮翻译都会记入下方「本次对话记录」气泡列表，可点「🖼 大字卡片」弹出全屏对照卡片方便投屏展示；记录仅保留本次页面，刷新后清空。
3. **手语演示（60 秒）**：
   - 打开手语页，上方是 **3D 演示模型舞台**：可拖拽旋转查看人物躯干与手臂位置；切换手语词时，模型播放对应的内置动作（挥手 / 竖拇指），其余词保持待机姿势。
   - 每个词详情页含：手位对照、多语言标签（英 / 日 / 俄）、动作分解（三步）、使用场景、要点提示和一句演示话术；手势分解以平面示意图为准。
   - 互译页里遇到「你好 / 谢谢 / 医院 / 多少钱 / 早上好 / 对不起 / 再见」等已收录词，结果区会出现「🤟 查看对应手语」按钮，点击直接跳转到对应手语词。
   - 摄像头只是备选取景：需要时可开启拍摄 / 上传图片，再点对应词确认；打不开直接点词卡或按 1–7，不影响演示。
4. **收尾与边界（40 秒）**：在「答辩说明」页讲清评测设计、当前边界和后续规划。

## 四、答辩边界口径（务必说清）

- 手语仅为 **7 个孤立常用词**的动作示意图演示，**不做**连续手语识别，**不做**手语语音 / 动画生成。
- 3D 舞台使用开源机器人占位模型做躯干与手臂位置参照，**不是**写实手语动作捕捉；具体手势做法以平面示意图和动作分解为准。
- 方言文字来自离线演示词库；多语言长句在联网时由在线翻译接口完成，正式链路规划为 ASR → 术语库后编辑 → 翻译 → TTS。
- “双向”是**轮流式双向**（一方说完、出结果、另一方再回应），不是零延迟同声传译。
- 大一阶段核心工作：串起链路、整理术语表、做评测集和 baseline 对比，不自己训练大模型。
